# 🚦 RoadSense - AI Hazard Perception Trainer (MVP)

RoadSense is an AI-powered browser-based hazard perception training portal built specifically for Indian roads. This repository contains the working MVP (Minimum Viable Product) developed for the Google Startup Buildathon 2026.

-->🎯 Problem Statement
India loses over 170,000 lives annually on roads. Most crashes happen because drivers spot danger too late. Existing tools focus on rules, not on real-world early hazard detection. 

-->💡 Our Solution
We use AI to automate the creation of hazard perception tests. Our backend processes real Indian road videos (Driver's POV) and uses the "Google Gemini API" to detect hazards, assign timestamps, and generate scenario-based MCQs with instant feedback based on Indian Motor Vehicle Rules (MVA).

==>🛠️ Tech Stack
1.  Backend:** Python, FastAPI
2.  Database:** SQLite (SQLAlchemy)
3.  AI Engine:** Google Gemini API (Video Analysis & MCQ Generation)
4.  Frontend:** HTML, JavaScript, Tailwind CSS
5.  Deployment Ready:** Uvicorn, Render/Vercel (Planned)

==>✨ Key Features (Working MVP)
1.  Video POV Player:** Plays real Indian road videos with autoplay, fullscreen, and speed controls.
2.  AI-Generated MCQs:** Questions are dynamically served from the database, generated by Gemini.
3.  Instant Feedback:** Users get immediate right/wrong feedback with explanations and MVA rule references.
4.  Randomized Test:** Fetches 10 random scenarios for each test to prevent memorization.
5.  Navigation:** Users can skip, go back to previous questions, and review their answers.
6.  Scoring System:** Tracks user score and provides a final result screen.

-->⚙️ How to Run Locally

Follow these simple steps to run the project on your machine:

1. Clone the repository:
   git clone https://github.com/tejasvanandsharma-netizen/RoadSense-MVP.git

2. Navigate into the project directory:
   cd RoadSense-MVP

3. Install dependencies:
   pip install -r requirements.txt

4. Seed the database with AI-generated JSON data:
   python seed.py
   (This will create a roadsense.db file and populate it with AI-generated questions)

5. Run the FastAPI backend server:
   uvicorn main:app --reload

6. Open the Frontend:
   Double-click on `index.html` to open it in your browser, or use the VS Code Live Server extension.
