# RoadSense - AI Hazard Perception Trainer (MVP)

RoadSense is an AI-powered browser-based hazard perception training portal built specifically for Indian roads. This repository contains the working MVP (Minimum Viable Product) developed for the Google Startup Buildathon 2026.

## 🎯 Problem Statement
India loses over 170,000 lives annually on roads. Most crashes happen because drivers spot danger too late. Existing tools focus on rules, not on real-world early hazard detection. 

## 💡 Our Solution
We use AI to automate the creation of hazard perception tests. Our backend processes real Indian road videos (Driver's POV) and uses the **Gemini API** to detect hazards, assign timestamps, and generate scenario-based MCQs with feedback based on Indian Motor Vehicle Rules.

## 🛠️ Tech Stack
*   **Backend:** Python, FastAPI
*   **Database:** SQLite (SQLAlchemy)
*   **AI Engine:** Google Gemini API (Video Analysis & MCQ Generation)
*   **Frontend:** HTML, JavaScript, Tailwind CSS

## ✨ Key Features (Working MVP)
1.  **Video POV Player:** Plays real Indian road videos with autoplay, fullscreen, and speed controls.
2.  **AI-Generated MCQs:** Questions are dynamically served from the database, generated by Gemini.
3.  **Instant Feedback:** Users get immediate right/wrong feedback with explanations and MVA rule references.
4.  **Randomized Test:** Fetches 10 random scenarios for each test to prevent memorization.
5.  **Scoring System:** Tracks user score and provides a final result screen.
